Agent interfaces · Foundations

2024

SWE-agent: Agent-Computer Interfaces Enable Automated Software Engineering ↗

John Yang et al.

In brief. The paper treats the interface itself as part of the agent design problem: tools, feedback, and action formats can determine whether a capable model succeeds on a real repository.

  • ACI

Agent evaluation · Benchmark

2026

Terminal-Bench: Benchmarking Agents on Hard, Realistic Tasks in Command Line Interfaces ↗

Mike A. Merrill et al.

In brief. Realistic terminal tasks, repeated trials, and a failure taxonomy provide a richer view of long-horizon agents than a single headline score.

  • Agent evaluation
  • CLI
  • Long horizon

Context management · Efficiency

2026

SWE-Pruner: Self-Adaptive Context Pruning for Coding Agents ↗

Yuhang Wang et al.

In brief. Context selection is treated as an adaptive, goal-conditioned decision rather than a static retrieval step, connecting efficiency with agent performance.

  • Context management
  • Efficiency
  • Code retrieval

Formal verification · Repository level

2026

Vero: Can AI Agents Build Formally Verified Software Repositories? ↗

Zhe Ye et al.

In brief. Repository-level Lean tasks expose the gap between generating plausible code and delivering software whose implementation and proofs survive an independent formal audit.

  • Lean 4
  • Formal verification
  • Benchmark audit

Quantum optimization · Foundations

2023

Quantum Optimization with Arbitrary Connectivity Using Rydberg Atom Arrays ↗

Minh-Thi Nguyen, Jin-Guo Liu, Jonathan Wurtz, Mikhail D. Lukin, Sheng-Tao Wang, and Hannes Pichler

In brief. The paper maps arbitrary-connectivity optimization problems to maximum-weight independent set on unit-disk graphs for Rydberg-atom arrays.

  • MWIS
