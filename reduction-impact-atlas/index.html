How the scores are calculated / 计算方法

For each question, the program copies the frozen baseline, adds only that question's hypothetical directed rule, and compares directed reachability before and after. N counts newly reachable pairs of different problem identities. B measures additional variant coverage for problem pairs already reachable in the baseline. V counts all newly reachable concrete variant pairs. D½ sums 0.5 raised to the number of edges beyond the candidate edge in each pair's shortest witness chain. The direct and transitive counts partition N. Concrete variant gain is separately partitioned into the candidate pair, old upstream, old downstream, and both sides; these four counts sum to V. D½ is diagnostic because path length depends on how the graph represents reductions and bridges. Sort by N, B, then V; equal triples remain tied. Every changed pair shown below has a witness chain.

Documented definition bridges are part of the baseline, with their direction and evidence in bridges.json. Other name matches are provisional.
