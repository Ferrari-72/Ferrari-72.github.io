Q001 · AI-proposed scenario

BFS tree support → Horn satisfiability

Official baseline: N 1 · B 0 · V 1. With this bridge only: N 94 · B 0 · V 118.

The new bridge also changes the computed scores of 26 other board questions, because they share the same baseline graph. Rankings from the two baselines are not directly comparable.

Proposed baseline bridge: Horn satisfiability → graph node 220. The board target returns a satisfying assignment or NO-SOLUTION for an explicit Horn CNF formula. Every Horn CNF formula is a CNF formula. A solution of graph Satisfiability on the identical formula is therefore a legal board output, and NO-SOLUTION is preserved. The reverse direction is invalid because arbitrary CNF is not Horn.

Algorithmic consequence if the question rule is proved: If the unverified BFS-tree-support to Horn-SAT rule is correct and has polynomial construction and recovery, the source has a polynomial-time search algorithm because Horn-SAT can produce a witness or certify unsatisfiability in polynomial time.

Why the count needs caution: The large topology count mostly follows the Horn-SAT to general-SAT inclusion and the graph's broad SAT descendants. It must not be interpreted as 94 independent research breakthroughs.

Q057 · AI-proposed scenario

Common stable matching with two changed agents on each side → 2-SAT search

Official baseline: N 1 · B 0 · V 1. With this bridge only: N 94 · B 0 · V 119.

The new bridge also changes the computed scores of 26 other board questions, because they share the same baseline graph. Rankings from the two baselines are not directly comparable.

Proposed baseline bridge: 2-SAT search → graph node 91. The board target returns a satisfying assignment or NO-SOLUTION for explicit 2-CNF. Graph KSatisfiability<K2> is the two-literal search variant. Convert any shorter clauses to equivalent exact-two clauses with fresh variables, then restrict a graph solution to the original variables. An empty clause is handled by a fixed unsatisfiable two-clause instance. This preserves both witness and NO-SOLUTION outputs in one call.

Algorithmic consequence if the question rule is proved: If the unverified common-stable-matching to 2-SAT-search rule is correct with polynomial construction and recovery, the restricted common-stable-matching source has a polynomial-time search algorithm.

Why the count needs caution: Most of the 94 new problem-family relations arise because the graph contains many descendants of two-literal SAT. This reachability does not itself measure how consequential solving the restricted stable-matching question would be.
